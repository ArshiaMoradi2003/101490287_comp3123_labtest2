## 📌 Project Description  
This project is a weather dashboard built for **COMP3123 – Full Stack Development I (Lab Test 2)**.  
It displays real-time weather information for any city using the **OpenWeatherMap Current Weather API**.

The application features:
- City search functionality  
- Weather icons fetched from OpenWeatherMap  
- Custom UI/UX with modern layout  
- Dynamic updates based on API responses  
- React hooks (`useState`, `useEffect`)  
- Data passed between components using props  
- Fully deployed to a hosting platform
